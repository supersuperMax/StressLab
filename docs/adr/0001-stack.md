# ADR 0001. Технологический стек

- Статус: принято
- Дата: 2026-10-12
- Источник: `docs/architecture.md` §1, §8–10

## Контекст

FEM-APP — кросс-платформенный пакет МКЭ с модульной оболочкой в стиле VS Code, ядро под MIT, платные модули позже.
Нужны: большие сетки и 3D-сцена без потери производительности, нативный интерфейс на Windows, macOS и Linux,
порог входа для авторов модулей и доступ к открытым библиотекам CAE (OCCT, Gmsh, Netgen, VTK), почти все
из которых написаны на C++.

## Решение

| Область | Выбор |
|---|---|
| Ядро и тяжёлые модули | C++20 |
| Плагины, скрипты, адаптеры решателей | Python 3.12 (встроенный), привязки nanobind |
| Оболочка | Qt 6 Widgets + Qt Advanced Docking System, только в `shell/` |
| 3D-вид | VTK 9, только в `extensions/fem.results.viewer` и `shell/viewport` |
| Геометрия и сетки | OpenCASCADE, Gmsh (отдельный процесс), Netgen — с этапа «Препроцессинг» |
| Данные и история | JSON (детерминированный) + блоки HDF5/zstd по хэшу, libgit2 |
| Служебные библиотеки | fmt, spdlog, nlohmann/json, toml++, Eigen |
| Сборка | CMake ≥ 3.28, vcpkg (manifest mode), Ninja, пресеты `core-*` (без GUI) и `full-*` |
| Тесты | GoogleTest, pytest |
| Стиль | clang-format, ruff + black |
| CI | GitHub Actions: Windows x64, macOS arm64, Ubuntu |

Ядро (`core/`, `storage/`) собирается без Qt GUI и VTK (`FEM_BUILD_GUI=OFF`). GPL-компоненты (Gmsh, CalculiX)
запускаются только отдельными процессами и не линкуются. LGPL-библиотеки (Qt, Qt ADS, OCCT, Netgen) в дистрибутиве
линкуются динамически.

## Рассмотренные альтернативы

- **Rust для ядра** — OCCT, Gmsh, VTK, Qt пришлось бы подключать через незрелые FFI-обёртки.
- **Electron/Tauri с веб-визуализацией** — хуже на сетках в миллионы элементов, нативный бэкенд всё равно нужен.
- **Всё на Python** — GUI с большой 3D-сценой и GIL упираются в производительность.
- **Основа на FreeCAD/Salome** — их система модулей не даёт включения/выключения без перезапуска и условной
  видимости UI.

## Последствия

- Долгая первая сборка Qt (позже VTK, OCCT) через vcpkg: бинарный кэш vcpkg в CI с первого дня, большинство задач
  этапа 1 собирается пресетом `core-*`.
- Смена любой строки таблицы требует нового ADR (CLAUDE.md, «Стек»).
