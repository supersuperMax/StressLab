# StressLab: гайд по логотипу

## 1. Знак
**Идея.** Пластина с отверстием, классическая задача МКЭ о концентрации напряжений. Инженеры считают только её четверть, пользуясь симметрией. Здесь пластина собрана из четырёх модулей, а коралловый модуль подключается на место: так знак показывает главную фишку StressLab, модули в стиле VSCode.

**Версии** (`logo/svg/`):
| Файл | Где использовать |
|---|---|
| `stresslab-horizontal-*.svg` | основной логотип: сайт, README, шапки |
| `stresslab-stacked-*.svg` | квадратные места: обложки, заставка |
| `stresslab-symbol-*.svg` | символ отдельно: аватары, иконки модулей |
| `stresslab-symbol-small-color.svg` | символ для размеров 32 px и меньше (шире зазоры и отверстие) |
| `stresslab-wordmark-*.svg` | только надпись, когда символ уже стоит рядом |

Суффиксы: `color` на светлом фоне, `reversed` на тёмном (зазоры чуть шире, чтобы светлый знак не «расплывался»), `black` и `white` для печати и гравировки в один цвет.

## 2. Охранное поле
Вокруг логотипа держите свободное поле не меньше **ширины одного модуля пластины × 0,5** (примерно половина стороны плитки символа). Поле масштабируется вместе с логотипом.

## 3. Минимальный размер
| Версия | Экран | Печать |
|---|---|---|
| Горизонтальная | 96 px по ширине | 25 мм |
| Символ | 16 px (только версия `small`) | 6 мм |

## 4. Цвет
| Название | HEX | RGB | CMYK (ориентир) |
|---|---|---|---|
| Графит (основной) | #1B1F24 | 27 31 36 | 75 65 55 75 |
| Коралловый «горячий модуль» | #FF5A36 | 255 90 54 | 0 75 80 0 |
| Бумага (фон на тёмном) | #F4F5F7 | 244 245 247 | 3 2 1 0 |

Коралловый означает красный конец шкалы напряжений и используется только на одном модуле знака и для акцентов интерфейса. Значения CMYK ориентировочные: перед печатью попросите типографию подобрать их по пробе или назначить Pantone.

**Разрешённые пары:** цветной на белом или светлом сером · `reversed` на графите · белый на коралловом · чёрный на белом.

## 5. Шрифт
Словесный знак набран **Inter Display** (SemiBold «Stress» + Regular «Lab») и переведён в кривые. Inter распространяется по лицензии SIL OFL, для логотипов подходит. Для интерфейса и документации рекомендуется Inter.

## 6. Иконки приложения (`icons/`)
| Платформа | Файлы | Как подключить |
|---|---|---|
| Windows | `windows/StressLab.ico` (16–256 px), PNG по размерам | иконка exe и установщика |
| macOS | `macos/StressLab.icns`, `StressLab.iconset/` | `CFBundleIconFile` в Info.plist; сетка Apple: плитка 824 из 1024, скруглённые углы |
| Linux | `linux/hicolor/*/apps/stresslab.png`, `scalable/…svg`, `symbolic/…svg`, `stresslab.desktop` | скопировать в `/usr/share/icons/hicolor/` (или `~/.local/share/icons/hicolor/`), `Icon=stresslab` |
| Веб | `web/` (favicon.ico/svg, apple-touch, PWA 192/512, maskable, manifest, head-snippet.html) | сайт и документация |

Размеры 32 px и меньше нарисованы отдельной упрощённой версией.

## 7. Чего не делать
Не растягивать и не сжимать · не перекрашивать вне палитры · не поворачивать · не добавлять тени, обводки и градиенты · не перекрашивать в коралловый больше одного модуля · не «выравнивать» поднятый модуль (сдвиг и есть идея) · не набирать словесный знак заново шрифтом, только файлы из набора.

## 8. Открытые вопросы
- Товарный знак не проверялся: нужен поиск по базам (Роспатент, WIPO, EUIPO) и обратный поиск изображений.
- Мастера только в SVG; PDF/EPS для типографии нужно экспортировать в векторном редакторе.
- Иконки модулей (activityBar) можно строить из той же плитки-четверти, это естественное продолжение системы.
